# Student Score Analyzer

A simple **Student Score Analyzer** project developed in two different versions to demonstrate the evolution of the same application from basic Python and Object-Oriented Programming to data analysis with Pandas.

The project allows users to analyze students' scores, calculate averages, determine pass/fail status, find the best and worst students, and perform several other operations.

---

## 📌 Project Versions

This repository contains two versions of the project, each available in a separate branch.

### 1. Python / OOP Version

**Branch:** `python-version`

The first version is built using core Python concepts and Object-Oriented Programming.

### Features

* Show all students
* Calculate each student's average score
* Determine Pass / Fail status
* Find the student with the highest average
* Find the student with the lowest average
* Search for a student and display their scores
* Interactive command-line menu

### Main Concepts Used

* Python Classes and Objects
* `__init__`
* Instance attributes
* Methods
* Lists
* Dictionaries
* User input
* Basic data processing

---

### 2. Pandas Version

**Branch:** `pandas-version`

The second version implements the same general idea using **Pandas DataFrames** and introduces more practical data-analysis operations.

### Features

* Display all students
* Calculate student averages
* Determine Pass / Fail status
* Find the highest and lowest average
* Calculate total scores
* Sort students by average
* Classify students by performance level
* Display DataFrame information
* Display descriptive statistics
* Display each student's scores

### Main Concepts Used

* Pandas DataFrame
* `apply()`
* `lambda`
* `max()` / `min()`
* `sort_values()`
* `loc`
* `DataFrame.info()`
* `DataFrame.describe()`
* Creating and modifying columns
* Basic data analysis

## 🎯 Purpose

The main purpose of this project is to practice and demonstrate the transition from **basic Python programming and OOP** to **data manipulation and analysis with Pandas**.

Instead of creating two completely unrelated projects, the same problem was implemented using different approaches to better understand how data-processing techniques can evolve as new tools and libraries are introduced.

This project was created as part of my Python and Data Analysis learning journey.
